# Independent deterministic STAT-001 replay

No author implementation imports. Exact-integer probability masses implement weighted quantiles including the test-point infinity atom. Deterministic frozen inputs, all1500 coverage rows,16500 selected raw float-hex values and15 coverage summaries are replayed. This code was independently written before publication and its results were already known; this unit only makes it portable and independently reviewable. No new stochastic experiment, conditional validity theorem or practical ratio-estimation claim.

From the repository root with Python3.12 standard library:

    python3 problems/STAT-001/experiments/independent_review/verify_statistics.py . /tmp/stat-independent
    python3 problems/STAT-001/experiments/independent_review/test_negative_controls.py .

Outputs go to a caller-supplied directory; original archives/spec remain unchanged. Scope details and omissions are in statistics-independent-review.json. Parent STAT-001 remains OPEN.
